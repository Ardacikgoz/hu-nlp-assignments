# Natural Language Processing – Assignments

Assignments from the Natural Language Processing course at Hacettepe University, Department of Artificial Intelligence Engineering.

## Contents

- `ASS1/` – Byte Pair Encoding (BPE) tokenizer
- `ass2/` – N-gram language model
- `ass3/` – Logistic Regression & Naive Bayes text classifiers
- `ass4/` – Assignment 4
- `ass5/` – News classification and title generation

> Datasets and large model files are not included. Outputs of very large notebooks were cleared to stay within GitHub's file size limits.
